## 1. P0：架构层（必须先做，后面全部依赖）

### 1.1 用状态枚举替换 `Mode` + `Start` 两个变量

**现状**：`app.c:16` 只有 `Mode`（1–4）和 `Start`（0/1），没有待机态和故障态，无法表达“自检中 / 故障”。

**目标**：按《状态机图表.xlsx》v1.0 的 12 条转移实现。

**改法要点**：

```c
typedef enum {
    ST_IDLE = 0,      /* S0 自检待机 */
    ST_CIRCLE,        /* S1 */
    ST_SQUARE,        /* S2 */
    ST_OVAL,          /* S3 */
    ST_STAR,          /* S4 加分，先占位 */
    ST_FIXED,         /* S5 定距加分，先占位 */
    ST_FAULT          /* 故障 */
} CarState_t;
```

- 保留 `Mode` 作为“用户选中的路线编号”，`CarState_t` 作为“机器当前所处状态”，两者分离。
- `Key_Get()` 不再直接改 `Start`，改成产出“事件”：`EV_START` / `EV_STOP` / `EV_MODE`，由统一的状态转移函数处理。
- 状态转移函数放在 `App_Task()` 或 10 ms 任务里调用，禁止在中断里做。

**验收**：串口或 OLED 能显示当前状态名；按 STOP 后必回 `ST_IDLE`；任何状态下电机输出都可被 STOP 立即清零。

### 1.2 三套参数组结构（标定数据的载体）

**现状**：`circle/square/oval` 三个 `PID_t` 和 `Leftspeed/Rightspeed` 写死在 `app.c`，参数直接改源码。

**目标**：按路线组织一份参数表，切换路线时整组加载。

**改法要点**：

```c
typedef struct {
    PID_t   track;          /* 循迹环参数 */
    float   base_speed;     /* 基础速度 counts/5ms */
    float   diff_limit;     /* 差速上限 */
    uint32_t lap_pulse;     /* 一圈对应的左轮脉冲数 */
    uint16_t lost_ms;       /* 脱线判定时间 */
    const char *name;       /* OLED 显示名 */
} RouteParam_t;

extern RouteParam_t g_route[3];   /* 圆 / 方 / 椭圆 */
```

启动时把对应 `g_route[i].track` 拷进工作的 `circle` 实例；`DeltaSpeed` 用 `diff_limit` 限幅。

**验收**：改参数只改表、不碰逻辑；OLED 显示的名称来自 `name` 字段。

### 1.3 判圈与用时（三条路线的硬性验收项）

**现状**：没有任何圈数或里程统计，只能手动按停止。

**目标**：跑满一圈自动停车，OLED 显示完成与用时。

**改法要点**：

- 用左轮累计脉冲做里程：5 ms 里已经算出 `Leftspeed.Actual`（带符号增量），累加绝对值到 `total_pulse`。
- 每圈配额 `lap_pulse` 从参数组取，先填占位值，标定后替换。
- 计时：起点记 `HAL_GetTick()`，完成时算差值。
- 完成动作：`StopAndClear()` + 置 `ST_IDLE` + OLED 显示 “DONE / 用时”。

**验收**：手动模拟（Keil Simulator 里改 `encoder_cnt`）能触发一次且仅一次完成；重复触发不会重复计数。

### 1.4 故障态与故障码

**现状**：脱线 200 ms 后只是静默停车，看不出原因。

**目标**：进入 `ST_FAULT`，OLED 显示故障码，蜂鸣报警。

**改法要点**：故障码枚举 `E_LINE_LOST / E_TIMEOUT / E_DRIVER`；进故障态时 `Beep(500)`；`ST_FAULT` 只接受 RESET（长按 STOP 或重新上电）退出。

**验收**：OLED 能区分“正常停止”和“故障停止”。

## 2. P1：验收硬性项

### 2.1 版本号 + S0 自检

- 增加 `#define FW_VERSION "v1.0"`，S0 状态时 OLED 显示版本、温度、路线名。
- 上电已有 `Beep(100)`，满足“蜂鸣一声”。

### 2.2 OLED 增加第 6 行（Y=50）

当前只用到 Y=40（温度），Y=50 空闲。建议显示：`lap:1/1  t:12.3s` 或故障码。

### 2.3 串口帧尾改 `\r\n` + 温度阈值报警

**现状**：`UART_Transmit.c` 里是 `"Temperature :  %.1f\n"`，Windows 串口助手常需 `\r\n` 才换行。
**补充**：温度超过阈值（建议先设 60 ℃，可宏定义）时置 `temp_alarm`，并让 OLED 有标记。

### 2.4 串口接收：启停与切模式（发挥 10 分）

**现状**：USART1 只发不收。
**改法**：开 `HAL_UART_Receive_IT` 收 1 字节，`HAL_UART_RxCpltCallback` 里解析 `'s'` 启动 / `'p'` 停止 / `'1'..'4'` 选路线；回调里只置标志，动作交主循环处理（不要在中断里停车/改状态机）。

### 2.5 定距 1.0 m（S5，加分 ±5 cm）

复用 1.3 的里程计数，目标脉冲 = `lap_pulse` 按实测“每米脉冲数”换算；到达即停。

### 2.6 五角星 S4（加分，先占位）

只需在 `Mode` 循环里加一个档位 + 参数组占位，不实现也能先保留入口。

### 2.7 `STBY`（PA8）确认

**现状**：`gpio.c:57` 初始化为低，之后无人置高。
**动作**：确认驱动板是否真有使能脚。若有，在 `App_Init()` 里 `HAL_GPIO_WritePin(STBY..., SET)`；若按 AT8236 裸芯片无此脚，可忽略。

## 3. P2：质量与可维护性

### 3.1 加权偏差算一次

`app.c` 里对 `square/oval/circle` 各算了一遍同样的加权和，改成先算 `int16_t dev`，再赋给三个 `Actual`（或只算当前模式那一个）。

### 3.2 键值去魔数

`switch (Key_GetNum())` 里的 1/2/3 改成 `bsp_key.h` 中的宏或枚举，答辩时更好讲。

### 3.3 丢线期间差速处理

现在丢线未满 200 ms 时保留上次 `DeltaSpeed`。若实测在弯道丢线会冲出去，可改成每次乘 0.9 缓降，但**不要直接置 0**。

### 3.4 PID 参数填值（标定后）

`Leftspeed/Rightspeed` 建议先只给 `kp`（2~5 量级），`ki/kd` 先 0；循迹环同理从 P 起步。**没有实测数据前不要凭感觉填。**

### 3.5 NTC 常量核对

`bsp_ntc.h` 里 `NTC_SERIES_RESISTOR=10k`、`NTC_BETA=3950`、`NTC_ADC_FULL_SCALE=4095`。需确认两点：分压电阻实际阻值、NTC 在分压的上臂还是下臂（决定公式方向）。上板后用冰水和热水各测一次即可验证。

### 3.6 `Display()` 收成 switch

四个 `if` 改 `switch`，越界显示 `mode:error`，便于以后加 S4/S5。

## 4. 改完之后的无硬件自测

1. **Keil Simulator**：`Debug → Use Simulator`，在 `Display()`、状态转移函数下断点，手工改 `GPIOB->IDR` 喂灰度、改 `TIM3->CNT` 喂编码器，验证加权偏差、脱线计时、判圈触发。
2. **逻辑分析仪窗口**：加 `TIM2->CCR1/CCR2`、`GPIOA->ODR`，确认正反转时 IN1/IN2 配合正确。
3. **PC 端 PID 仿真**：把 `pid_compute()` 搬到 PC，用一阶惯性模型验证积分限幅与输出方向，先定 `kp` 量级。
